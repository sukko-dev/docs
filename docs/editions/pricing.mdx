# Pricing

All prices are **flat annual subscriptions** — no usage metering, no per-message fees. Tiers within an edition differ by licensed connection capacity.

## Community

**Free** — forever.

- 3 tenants, 500 connections, 1 shard
- The full data path: Kafka/Redpanda ingestion, message history, live gap recovery, REST publish
- Community support via [GitHub Issues](https://github.com/sukko-dev/sukko-issues/issues)

[Get Started](../quickstart)

## Pro

Production scale plus the operations surface: SSE transport, Web Push, per-tenant limits and quotas, tenant lifecycle, channel-topic routing, alerting, tracing, analytics, admin UI, token revocation, webhooks, and the connections API. Base edition limits: 50 tenants, 10,000 connections, 8 shards — higher tiers license higher connection caps.

| Tier | Licensed capacity | Price |
|------|-------------------|-------|
| **Pro** | Up to 10,000 connections | $7,500/yr |
| **Pro Growth** | Up to 50,000 connections | $15,000/yr |
| **Pro Scale** | Up to 150,000 connections | $30,000/yr |

- Email support

[Contact Sales](https://sukko.dev/pricing)

## FAQ

### Can I try Pro features before purchasing?

Yes. Contact us for a trial license key — full Pro features for 14 days.

### What happens when my license expires?

Sukko falls back to Community edition limits. Existing connections are not dropped, but new connections beyond Community limits are rejected.

### Is there a self-hosted requirement?

Yes. Sukko is BYOC (Bring Your Own Cloud). All editions run in your infrastructure. There is no hosted/SaaS option — you maintain full control of your data.
